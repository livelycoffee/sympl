# SYMPL - Secure Yet Memorable Passphrase Logic

Its easy
1. Think of any two unrelated but memorable sentences (3-5 words each).
2. Interleave them in a memorable pattern.
3. Optionally, add a number or two if you want.

And thats it! You have a secure passphrase whihc is easy to remember!

Advantages:
1. Harder to crack using pattern-matching
2. Ressiliant against diret dictionary attacks
3. High passphrase length achieved without complexity

Disadvantages:
1. Weaker security when using extremely common phrases
2. Weaker security when using phrases that are related

Feel free to use this in any of you works! 
Our goal is to eventually replace the standard "8 characters, one capital..." with "Stuck? Use SYMPL!"
And if you want to improve it further, feel free to contribute.
